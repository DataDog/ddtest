## Defects found in the original round

The original six trials are retained separately. Equal native suite outcomes did
not turn missing telemetry or invalid controls into passes:

- dry-inflector exposed normalized wire names and anonymous RSpec descriptions
  that differ from native generated names. Rake's forced `--pattern` also loaded
  the full suite during controls. The corrected observer preserves native names,
  applies the installed tracer's pure wire-name formatting, matches anonymous
  examples through independently observed `scoped_id`, and confines probe patterns.
- i18n exposed array normalization in Minitest test names (`[...]` becomes `ARRAY`).
  Both original agents observed 1,607 passing tests, but telemetry reconciliation
  stayed inconclusive. All six controls already passed.
- TZInfo's three Rake test processes executed the passing control three times;
  the failing control aborted Rake after one. Probe ownership now selects one
  process while retaining the real task and its initialization.
- The original Claude dry-inflector trial renamed two anonymous examples and
  selected direct RSpec for its final controls. That is recorded as a workaround,
  not an unchanged-suite success. The corrected trials preserve those examples.

Regression coverage exercises RSpec's Rake pattern, anonymous examples, normalized
RSpec/Minitest names, multi-process Minitest tasks and incorrect/missing telemetry
identities. Real-framework integration checks also retain equal existing failures,
source coverage requirements, all six features, stale/check-only evidence, missing
lockfiles and incompatible CI selections.

Use the pinned commits above, build this branch, and run once per project/agent
with a fresh output directory, following `../SKILL.md`:

```sh
python3 skills/ddtest-onboarding-eval/scripts/run_eval.py \
  --repo <public-repository-url> --ref <pinned-commit> \
  --ddtest /absolute/path/to/ddtest --agent <codex-or-claude> \
  --ruby /absolute/path/to/ruby-3.4.9 \
  --setup-command 'bundle install --jobs 4 --retry 2' \
  --output /absolute/path/outside-target/<new-output-directory> \
  <process-local-MCP-isolation-flags>
```
